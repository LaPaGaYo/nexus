# docs/architecture — index

This directory mixes **current-state architecture docs** with **historical provenance** (briefs, RFCs, audits, and session logs from past work tracks). The two are not interchangeable: the historical files were accurate when written but predate later reorganizations (e.g. the taxonomy-v2 / `runtimes/` move). **An agent or contributor treating a historical brief as current may act on stale paths.** Verify any path, module name, or command against the code before relying on it.

## Current-state docs (keep in sync with code)

- `context-diagram.md` — layered system view
- `runtime-flow.md` — how one invocation flows from command to provider calls + artifact writes
- `repo-taxonomy-v2.md` — the repo's physical taxonomy (target tree)
- `repo-path-inventory.md` — generated by `scripts/repo/path-inventory.ts` (do not hand-edit; `bun run repo:inventory`)

## Historical provenance (point-in-time records — verify before relying)

Everything else here is a record of past work and is **not** maintained as current-state documentation:

- `track-*-*.md` — Track C/D/E/F brief + RFC series (command-surface, taxonomy reorg, skill strengthening, darwin upgrades)
- `phase-*.md` — phase plans/briefs/backlogs
- `skill-strength-audit*.md` — dated skill-strength audit snapshots (v2/v3/v4)
- `session-summary-*.md` — dated session logs
- `*-proposal.md`, `post-audit-cleanup-plan.md` — point-in-time proposals/plans

Some of these already carry an inline historical-context banner; this index covers the rest. When a historical doc's content becomes current-state truth, promote the relevant section into one of the current-state docs above rather than treating the brief itself as authoritative.
